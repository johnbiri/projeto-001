# Nova Versão | Cintura Fitness

Pasta criada para desenvolver a nova landing page sem alterar a versão atual.

## Estrutura

- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/images/`
- `assets/icons/`
- `assets/logo/`

## Observação

Esta estrutura é uma base inicial. O layout, copy, seções e interações devem ser definidos a partir do novo direcionamento do cliente.
